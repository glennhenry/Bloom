Not to be confused with the [Bloom K-pop cafe](/docs/cafe), this section is the generic Bloom forum.

### Overview

Bloom network is more similar to Reddit than traditional vBulletin forum.

People creates a "sub-network" for a particular topic. Users can post within each sub-network. Other users can replies and each reply can be commented (flat-hierarchy).
